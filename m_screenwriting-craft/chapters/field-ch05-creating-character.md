# 第 5 章：创造人物（菲尔德《电影剧本写作基础》）

## 核心要义
写剧本有两条路：**先有想法再把人物装进去**（"三个家伙抢银行"→设计适合的人物），或**先创造人物，让需求、动作和故事从人物身上长出来**。本章用一堂课堂练习完整演示第二条路：通过"从一般到特殊、从来龙去脉到内容"的连环提问，一个波士顿女人萨拉·唐珊德在一小时内长出了一部完整剧情片《防护措施！》。

## 提出的框架
- **两条创作起点**
  - 想法先行：《洛奇》《三伏天下午》——先有高概念前提，人物服务于想法。
  - 人物先行：《艾丽丝不再住在这儿了》《归家》《转折点》——人物处境一旦成立，需求与故事自然涌现。
- **课堂人物创作法（提问—试错—收敛）**
  1. 定基本坐标：性别、年龄（考虑"银行肯投资"的明星年龄段，不必过于具体）、姓名、城市。
  2. 建内在来龙去脉：父母身份与关系、出生年代（用减法算年份）、独生与否、童年动力（为讨父亲喜欢当假小子→与母亲作对→投射到日后与男人的关系）。
  3. 教育与反叛：中学性格、大学专业、政治行动——观点与态度在此成型。
  4. 十字路口：人物离家/进城，进入外在生活；按三 P 安排职业、个人、私生活。
  5. 施加外在力量：把人物放进具体历史时刻（1972 年的纽约：尼克松、越战、麦戈文、水门事件）。
  6. 寻找"钩子/激发点"：一个有争议、人人议论的戏剧性前提（核电站安全丑闻）。
  7. 长出三幕：情节点 I、第二幕障碍链、情节点 II、结局。
- **结尾三型**：**向上**（诸事顺利，英雄胜利）、**暧昧/悲哀**（留给观众设想）、**向下**（所有人死去）。菲尔德明确建议优先"向上"的结尾。

## 关键概念
- **钩子（Hook）/ 激发点**：能激发创作反应、把人物带入特定戏剧性动作的事件或事变。
- **为戏剧性目的勾勒冲突**：家庭"像所有家庭一样"，但要尽可能多地挖掘细腻冲突备用，用不用由效用决定。
- **商业意识**：制片厂老板的两个问题——"剧本讲的是什么？""由哪个明星来演？"人物设定要能想象出可投资的演员。
- **混乱是过程的一部分**：提问中不断自我反驳、提出又否决，"我们必须使自己'找到'它"。

## 思维模型
- 把人物当**树根**：根（传记与处境）扎得够深，故事枝干会自己长出来。
- 用**历史年表**给人物加压：真实的时代事件（战争、丑闻、运动）是现成的外在力量与冲突源。
- 把每个创作决定都过一遍"**能起作用吗（能起戏剧效用吗）**"，不起作用就换，不执着于课堂上谁提的答案。

## 反面模式
- **人物与时代脱节**：1972 年在纽约却不与越战/水门发生任何关系——放弃了最廉价有力的外在冲突。
- **职业选择不符合人物**：让萨拉当律师必须给出她的理由（想改变政治制度），否则是作者硬塞。
- **执着于悲剧/向下结尾**：六十年代流行"全死光"，但菲尔德认为七十年代后观众要明确结局；除了被捕被杀还有更好的处理。
- **追求一小时就完美**：课堂成果只需"扎实的人物+富有戏剧性的前提"，细节可后续生长。

## 实战范例（《防护措施！》Safeguard! 的完整生成）
- **人物**：萨拉·唐珊德，1954 年生，波士顿上层独生女；父亲是保守的名医、想要儿子，她当假小子讨父欢；母亲是前教师；拉德克利夫大学政治学专业，参加静坐抗议；1972 年到纽约为麦戈文竞选工作。
- **钩子**：核电站工人受放射性污染，案子交到她所在的法律事务所。
- **情节点 I**：她发现致命污染源于安全措施不健全，不顾威胁与阻碍决心采取行动。
- **第二幕障碍链**：工会因她是女人不信任她、官方拒绝她进厂、有人向她窗户扔砖头、政界推诿、事务所施压、父母反对、男友（离婚带两孩的律师）骂她"偏执"关系破裂；支持她的只有电站工人和一个想搞新闻的记者（兼爱情线）。
- **情节点 II**：记者交给她证明政治徇私、牵涉多名官员的证据——动作再次转向。
- **结局（向上）**：她在工人与新闻机构帮助下公开揭露政治徇私，电站被关闭直至安全标准重建，英雄胜利。

## 教学与诊断提示
- 带学员做现场共创：一次只问一个问题、每个问题只取一个答案，不喜欢就换；从城市/年龄/姓名一路问到时代钩子。
- 检查人物先行的故事是否成立：删掉事件后，人物本身是否仍有趣？她的职业选择有无个人理由？
- 诊断第二幕：列出至少 5 个来自不同方向的障碍（体制、同行、家庭、亲密关系、自我怀疑），少于 3 个方向说明对抗单薄。

## 关键要点
1. 想法先行或人物先行都成立，人物先行时用连环提问让故事自己浮现。
2. 提问顺序：基本坐标 → 家庭动力 → 教育/反叛 → 独立十字路口 → 时代外力 → 钩子 → 三幕。
3. 家庭冲突要为戏剧性目的刻意挖掘，但保留"用不用看效用"的选择权。
4. 主角的职业与每一步选择都必须有属于人物自己的理由。
5. 默认给观众一个明确、有力的解决；新手优先尝试向上结尾。
